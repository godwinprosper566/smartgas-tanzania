# SmartGas Tanzania - Current Status

## Working Features
- Place gas orders (Household / Vehicle / Business)
- Live price calculation
- Track order by ID
- Staff login / logout
- Staff dashboard
- Order management (status + payment)
- Status flow: Pending → Out for Delivery → Delivered
- Payment status: Unpaid → Paid
- Search and filters
- Daily report + print
- WhatsApp quick contact
- Notes field

## How to run locally
1. cd smartgas_web
2. python manage.py runserver
3. Open http://127.0.0.1:8000/
