# SmartGas Tanzania

Simple gas ordering system for households, vehicles (CNG), and businesses.

## Features
- Place gas orders
- Track orders by ID
- Staff login
- Dashboard
- Order management (status + payment)
- Daily report
- WhatsApp quick link

## How to run
1. python manage.py runserver
2. Open http://127.0.0.1:8000/

## Staff Login
Use the superuser you created with:
python manage.py createsuperuser
